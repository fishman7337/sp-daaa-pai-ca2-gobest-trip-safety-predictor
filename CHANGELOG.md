# Changelog

All notable changes to this project will be documented here.

## [0.1.0] - 2026-06-10

- Reworked the submission into a public, code-first repository.
- Added MIT license, conduct, contributing, security, architecture, data notes, and model card.
- Added GitHub Actions CI and Windows executable build workflow.
- Centralized schema metadata for validation, preprocessing, and UI labels.
- Made prediction source explicit for model versus heuristic fallback paths.
- Improved batch output booking IDs and prediction-source exports.
- Added tests for validation edge cases, fallback behaviour, model loading, batch outputs, and store subscriptions.
